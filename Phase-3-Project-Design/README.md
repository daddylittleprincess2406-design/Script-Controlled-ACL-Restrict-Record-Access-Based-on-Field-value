# Project Design

## Project Title
Script-Controlled ACL – Restrict Record Access Based on Field Value

## Design Overview
The system uses ServiceNow Access Control Lists (ACLs) with scripting to control access to records based on field values.

## Main Components
- ServiceNow Application
- User Roles
- ACL Rules
- Script Logic
- Database Records

## Workflow
User → ACL Check → Script Validation → Field Value Check → Access Granted or Denied
