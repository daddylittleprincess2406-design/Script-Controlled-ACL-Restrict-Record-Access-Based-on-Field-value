# Project Testing

## Project Title
Script-Controlled ACL – Restrict Record Access Based on Field Value

## Testing Objective
To verify that the ACL correctly allows or restricts record access based on the specified field value.

## Test Cases

### Test Case 1
Verify access when the field value satisfies the defined condition.

### Test Case 2
Verify that access is restricted when the field value does not satisfy the condition.

### Test Case 3
Verify the ACL behavior for different user roles.

## Expected Result
The ACL should correctly grant or restrict access according to the configured field-value condition.

## Testing Status
Testing is performed to validate the functionality and access restrictions of the project.
