# Project Documentation

## Project Title
Script-Controlled ACL – Restrict Record Access Based on Field Value

## Project Description
This project implements a scripted Access Control List (ACL) in ServiceNow to restrict record access based on a specified field value.

## Technologies Used
- ServiceNow
- Access Control Lists (ACL)
- JavaScript

## Working Principle
The ACL checks the required field value and applies the configured access condition before allowing the user to access the record.

## Benefits
- Improves record security
- Provides field-based access control
- Helps protect restricted information
- Supports role-based access management

## Conclusion
The project demonstrates how scripted ACLs can be used to control record access in ServiceNow.
