# Project Development

## Project Title
Script-Controlled ACL – Restrict Record Access Based on Field Value

## Development Activities
- Configure the required ServiceNow application.
- Create and configure the required ACL.
- Add the required script logic.
- Define the field-value based access condition.
- Create test records and users.
- Implement and verify the access restrictions.

## Implementation
The ACL script checks the specified field value and controls whether the user is allowed to access the record.

## Expected Result
Users should be able to access records only when the defined field-value conditions are satisfied
