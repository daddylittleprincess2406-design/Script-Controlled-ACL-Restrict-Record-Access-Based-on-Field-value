# Brainstorming & Ideation

## Project Title
Script-Controlled ACL – Restrict Record Access Based on Field Value

## Project Idea

This project implements a script-controlled Access Control List (ACL) in ServiceNow to restrict record access based on the Branch field value.

## Problem Statement

Users should only be able to view records that belong to their permitted branch, while administrators should retain full access.

## Proposed Solution

Allow users belonging to the EEE branch to view records where the Branch field is set to EEE, while administrators retain full access.
